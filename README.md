# Exercícios em C

Repositório destinado à prática e consolidação dos **conceitos básicos de programação em C**, desenvolvido durante as aulas do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

Os exercícios foram implementados conforme os conteúdos apresentados em sala de aula, com foco no aprendizado progressivo da linguagem e da lógica de programação.

---

## Conteúdos Praticados

- Lógica de programação
- Estruturas condicionais (`if`, `else`, `switch`)
- Estruturas de repetição (`for`, `while`)
- Operações matemáticas básicas
- Entrada e saída de dados (`printf` e `scanf`)
- Organização simples de código

---

##  Arquivos do Repositório

- `IMC.c` — Cálculo de índice de massa corporal  
- `Jogo-da-velha.c` — Implementação básica do jogo da velha  
- `controle_acesso.c` — Controle simples de acesso por condições  
- `fila.c` — Implementação básica de fila  
- `pilha.c` — Implementação básica de pilha  
- `maior_numero.c` — Identificação do maior número  
- `media_nota.c` — Cálculo de média de notas  
- `positivo_negativo.c` — Verificação de número positivo ou negativo  
- `tabuada.c` — Geração de tabuada

---

##  Objetivo do Repositório

- Fixar os fundamentos da linguagem C  
- Desenvolver raciocínio lógico  
- Criar uma base sólida para estudos futuros em programação  

---

##  Observação

Repositório com **finalidade educacional**, sem foco em otimização ou aplicações comerciais.
